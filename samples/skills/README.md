# Agent Skill Samples

This directory contains sample `SKILL.md` files that agent harnesses can copy or adapt.

- [`pkmcp-codebase-questions/SKILL.md`](pkmcp-codebase-questions/SKILL.md): an agent-facing operating contract for using a configured Project Knowledge MCP server to answer codebase, project-memory, architecture, and evidence-gathering questions.

The samples are intentionally harness-neutral. If your MCP client prefixes tool names with the server name, keep the same semantics and map the tool names to the names exposed by your harness.
